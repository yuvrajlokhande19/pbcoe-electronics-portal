Circuit Calibration Protocol

Scroll to run the department's signature gamified sequence — watch the oscilloscope respond as you calibrate each stage of the signal chain.

STAGE_01 // SIGNAL SOURCE

Generate the Carrier

Every system begins with a clean source. In Semester 1 you'll build Wien bridge oscillators and function generators by hand — the same waveform now sweeping on the scope.

STAGE_02 // DIGITAL SWITCHING

Square Up the Logic

Analog meets digital. Flip-flops, counters, and 555 timers convert smooth carriers into crisp clock edges that drive every processor on Earth.

STAGE_03 // POWER MODULATION

Gate the Energy

PWM is how modern electronics breathe — motor drivers, SMPS units, Class-D amplifiers. You'll tune duty cycles on real MOSFET breadboards in our Power Lab.

STAGE_04 // SIGNAL CONDITIONING

Filter Out the Noise

Real signals are messy. Active filters, op-amp stages and ADC pipelines scrub interference before a single bit reaches your microcontroller.

STAGE_05 // SYSTEM LOCK

Achieve Lock. Ship Product.

I&Q aligned, jitter minimized, protocol stable. This is the moment an engineering student becomes an engineer — and where your journey at PBCOE begins.

// INFRASTRUCTURE

Facilities That Feel Like Industry

Not display-case labs. Working environments with the same instruments used in semiconductor fabs and aerospace benches.


μC

Embedded Systems Lab

ARM Cortex-M dev stations, STM32 & ESP32 fleets, logic analyzers at every bench and a live GPIO wall for the whole batch.
VLSI

VLSI & Fabrication Suite

Xilinx Vivado workstations, Basys-3 FPGA boards, mask-less PCB prototyper delivering boards in under 40 minutes.
RF

RF & Antenna Range

Vector network analyzer up to 8.5 GHz, anechoic test corner, and SDR benches running GNU Radio experiments.
IoT

IoT & Robotics Forge

LoRaWAN gateways, ROS2 robot fleet, and a printed sensor lab — home of two national robotics champions.
SIM

Simulation Center

MATLAB, LTspice, Cadence Virtuoso seats with GPU compute for SPICE-level device physics coursework.
⚡

Power Electronics Bay

Regenerative grid simulators, 4-channel scopes to 350 MHz, and thermal cameras for converter design projects.

Signature Course Tracks

Four-year B.Tech curriculum engineered backwards from what the semiconductor industry actually hires for.


ECE-201

Digital System Design with HDL

From truth tables to synthesizable Verilog on real FPGAs. Includes timing closure and verification fundamentals.

SEM 3 · 4 CR
ECE-305

Microcontrollers & Embedded C

Bare-metal programming, RTOS concepts, peripheral drivers and low-power firmware patterns on ARM Cortex-M.

SEM 5 · 4 CR
ECE-308

Analog IC Design Foundations

Two-stage op-amps, bandgap references and noise analysis using Cadence Virtuoso with tape-out-style reviews.

SEM 6 · 3 CR
ECE-402

VLSI Physical Design Automation

Floorplanning to routing: industry flow with open-source tools (OpenROAD) plus DRC/LVS sign-off methodology.

SEM 7 · 3 CR
ECE-410

Embedded Security & Trust

Secure boot chains, side-channel basics, and hardware root-of-trust design — one of India's few UG electives here.
