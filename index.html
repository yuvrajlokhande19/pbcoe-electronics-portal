STAGE_01 // SIGNAL SOURCE

Generate the Carrier

Every system begins with a clean source. In Semester 1 you'll build Wien bridge oscillators and function generators by hand — the same waveform now sweeping on the scope.

STAGE_02 // DIGITAL SWITCHING

Square Up the Logic

Analog meets digital. Flip-flops, counters, and 555 timers convert smooth carriers into crisp clock edges that drive every processor on Earth.

STAGE_03 // POWER MODULATION

Gate the Energy

PWM is how modern electronics breathe — motor drivers, SMPS units, Class-D amplifiers. You'll tune duty cycles on real MOSFET breadboards in our Power Lab.

STAGE_04 // SIGNAL CONDITIONING

Filter Out the Noise

Real signals are messy. Active filters, op-amp stages and ADC pipelines scrub interference before a single bit reaches your microcontroller.

STAGE_05 // SYSTEM LOCK

Achieve Lock. Ship Product.

I&Q aligned, jitter minimized, protocol stable. This is the moment an engineering student becomes an engineer — and where your journey at PBCOE begins.

Core Academic & Hands-on Laboratory Courses

Approved RTMNU NEP Scheme for B.Tech Electronics & Telecommunication Engineering

ET501T

Embedded Systems

Faculty: Mr. Suhas D. Kakde (Academic Coordinator)

Microcontroller architecture, ARM Cortex programming, timers, UART/SPI/I2C communication, and sensor interfacing.

4 Credits ET503P Lab Co-requisite
ET502T

Communication Electronics

Faculty: Mrs. Jayshri Salodkar (Shelke)

Modulation schemes, RF transceivers, superheterodyne receivers, noise analysis, and digital link budgets.

4 Credits ET504P Lab Co-requisite
ET505T

Signals & Systems

Faculty: Mrs. Nisha N. Naukarkar

Continuous and discrete-time signals, LTI systems, convolution, Fourier transform, and Z-transform system stability.

3 Credits RTMNU Theory
ET506-1T

Digital System Design using VHDL

Faculty: Dr. Jayant Y. Hande

VHDL syntax, behavioral modeling, finite state machines (FSM), testbenches, and FPGA hardware synthesis.

3 Credits ET507P FPGA Lab
IOT-NODE

Biometric IoT System

Incharge: Mr. Suhas D. Kakde & Dr. Jayant Hande

Real-time R307 optical fingerprint scanner connected to ESP32 node and Supabase Cloud PostgreSQL backend.

Active Hardware Open Biometric Station ⚡
